## Task B1: Real or Fake Job Postings (EMSCAD) Dataset

**Source:** Real or Fake Job Posting Prediction (EMSCAD), University of the Aegean  
**Kaggle:** `https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction`  
**Direct Download Mirror:** `https://raw.githubusercontent.com/hoangsonww/Spot-the-Scam-AI-Job-Fraud/master/data/fake_job_postings.csv`

### Dataset Details
- **Samples:** 17,880 postings
- **Target:** `fraudulent` (0 = Real: 17,014 [95.2%], 1 = Fake: 866 [4.8%])
- **Modality:** Mixed (Structured categorical/binary flags + Free text fields)

### Download Instructions

**Option A (Automatic):**
The notebook `B1_notebook.ipynb` will automatically fetch `fake_job_postings.csv` into this directory if it is not already present.

**Option B (Manual):**
1. Download `fake_job_postings.csv` from Kaggle or the repository mirror above.
2. Place `fake_job_postings.csv` into this `data/` folder.

*Note: Per assignment rules, the raw `.csv` file is excluded from Git via `.gitignore`.*
